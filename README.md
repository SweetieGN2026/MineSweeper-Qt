# MineSweeper - C++ Qt 扫雷游戏
> 大二计算机学习项目，基于C++ + Qt6实现经典扫雷，**逻辑层与UI界面完全分离**，游戏核心算法独立封装，可移植复用。
> 核心算法：BFS洪水填充、首点保护（第一次点击永远不会踩雷）、地雷重分配、插旗计数、胜负判定。

## ✨ 项目特性
1.  **首点击保护**：第一次左键点到地雷时，自动将地雷迁移到棋盘其他空位，保证首下永不踩雷。
2.  **BFS洪水扩散**：空白格子自动大范围翻开，使用队列BFS，避免DFS递归大面积棋盘栈溢出。
3.  **插旗标记**：右键可以插旗/取消插旗，旗子数量上限等于总地雷数量，实时计算剩余地雷数。
4.  **胜负判定**：
    - 失败：踩到地雷，游戏结束，自动翻开全部地雷
    - 胜利：所有**非地雷格子全部翻开**即判定获胜
5.  边界安全校验：所有格子操作前做越界判断，非法操作不会崩溃。
6.  随机布雷：随机种子全局仅初始化一次，短时间连续点新游戏不会生成相同雷图。

## 📦 技术栈
- C++17
- Qt6（GUI界面，仅负责渲染与鼠标事件，**游戏逻辑完全独立在MineSweeper类**）
- CMake 构建
- STL：`vector`二维数组存储棋盘，`queue`实现BFS

## 📝 关键算法知识点（复习笔记，方便以后回看）

1. **布雷逻辑**
循环随机生成坐标，如果该位置没有地雷，就放置地雷，直到放满设定地雷总数。
2. **邻域地雷计数 computeAdjacent ()**
遍历棋盘每一格，扫描周围 8 个方向，统计周围地雷数量存入 adj 数组。
3. **首点保护 moveMine ()**
如果第一次点击直接点到地雷：把当前格子地雷移除，扫描棋盘找到第一个空白格子，把地雷移过去，**重新计算全部格子邻域雷数**。
4. **BFS 洪水填充 bfsReveal ()**
当翻开空白格（周围雷数 = 0），自动向 8 邻域扩散翻开。
> 
> 选用 BFS（队列）而不是递归 DFS：防止大棋盘深度递归造成栈溢出。
> 重要细节：BFS 扩散时**跳过已经插旗的格子**，不会自动翻开旗子。
5. **胜负判断 isWin ()**
遍历整个棋盘，只要还有任意一个非地雷格子没有翻开 → 未胜利；全部翻开则胜利。

## ⚠️ 边界约束 & 限制

1. 插旗数量不能超过地雷总数，达到上限后无法继续插旗
2. 已经翻开的格子，不能插旗
3. 游戏结束后，不能再执行翻开 / 插旗操作
4. 棋盘行列、地雷数量必须合法：地雷不能铺满整个棋盘
